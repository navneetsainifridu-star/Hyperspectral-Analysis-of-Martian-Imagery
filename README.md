# Hyperspectral Analysis of Martian Imagery Using ArcGIS Pro

## Project Overview
This project demonstrates the use of GIS and Hyperspectral Remote Sensing techniques to analyze Martian surface imagery, focusing on potential mineral identification in Jezero Crater, Mars.

## Project Details
- Software: ArcGIS Pro
- Study Area: Jezero Crater, Mars
- Data: Martian MTRDR Hyperspectral Imagery
- Domain: GIS and Remote Sensing

## Objectives
- Visualize hyperspectral imagery.
- Apply different RGB band combinations.
- Identify potential mineral-related features.
- Identify and label anomalous spectral bands.
- Generate and interpret spectral profiles.
- Compare spectral signatures with reference mineral data.

## Methodology

### 1. Hyperspectral Data Visualization
Added and visualized 489-band hyperspectral imagery in ArcGIS Pro.

### 2. False Color Composite
Applied RGB band combinations:
- Red: BD2500_2
- Green: BD1300
- Blue: D2300

### 3. Bad Band Identification
Identified the anomalous wavelength band at 2800.35 nm and applied the Label Bad Bands raster function.

### 4. Spectral Profile Analysis
Generated a spectral profile and examined absorption features between 2200 nm and 2600 nm.

### 5. Mineral Signature Comparison
Compared the observed spectral profile with the Fe/Ca-Carbonate reference spectral signature.

## Key Observations
- Potential carbonate-related spectral features were identified.
- Absorption features were observed near 2300 nm and 2500 nm.
- Different spectral combinations helped visualize mineral-related surface patterns.

These observations indicate potential mineral signatures and are not independent geological confirmation.
